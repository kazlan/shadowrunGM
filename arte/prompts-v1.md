# Prompts de arte para llegar a v1

Estos prompts están pensados para generar un moodboard y assets originales para **shadowHack**. No deben pedir copias de screenshots, sprites, logos ni estilos exactos de propiedades existentes. La dirección visual es: **PWA móvil vertical, cyberpunk abstracto, terminal retro, geometría neón, pantalla de deck portátil, tensión de intrusión digital**.

## Reglas generales para todos los prompts

- Formato preferente: vertical 9:16 para fondos y pantallas, 1:1 para iconos/logos.
- Paleta base: negro azulado `#050716`, cyan neón `#33ffcc`, magenta `#ff3df2`, rojo alerta `#ff3d6e`, amarillo dato `#f8d66d`.
- Evitar texto pequeño ilegible salvo que se pida como textura abstracta.
- Evitar logos reales, marcas reales, nombres de empresas reales y símbolos reconocibles de franquicias.
- Pedir siempre composición limpia, usable como UI de móvil y con espacios para HUD.
- Para assets finales, generar variantes con y sin fondo transparente.

## 1. Logo principal de shadowHack

**Prompt:**

> Diseña un logo original para una PWA móvil llamada “shadowHack”, sobre intrusión digital cyberpunk y mapas de nodos. Icono geométrico abstracto, mezcla de hexágono, núcleo de red y conector de cyberdeck, paleta negro azulado, cyan neón y magenta. Debe funcionar en tamaño pequeño como icono de app, silueta clara, alto contraste, sin marcas reales, sin referencias a franquicias existentes, sin texto diminuto, estilo vectorial limpio, fondo transparente, 1:1.


**Variantes a pedir:**

- Logo solo símbolo.
- Logo con wordmark “shadowHack”.
- Versión monocroma cyan.
- Versión maskable icon para PWA.
