# Referencias de inspiración y límites

## Inspiraciones permitidas

- Ficción cyberpunk general.
- Interfaces de terminal retro, scanlines, mapas de nodos y geometría abstracta.
- Juegos históricos con representación visual de ciberespacio como referencia de alto nivel.
- Mecánicas originales de exploración, riesgo, alerta, trazado y extracción.

## No usar

- Sprites, screenshots, logos, nombres o textos propietarios.
- Tablas o reglas exactas de juegos de rol comerciales.
- Pantallas copiadas 1:1 de videojuegos existentes.
- Nombres registrados si el proyecto se publica de forma abierta o comercial.
- Acusaciones o contenido dañino sobre empresas reales.

## Criterio creativo

La empresa real solo es un ancla contextual para generar una semilla. Dentro del sistema, la experiencia usa aliases, iconografía y lenguaje propios.
